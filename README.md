# מערכת ניהול סטודיו - SPORTIME 

מערכת צד-שרת (Backend) חזקה ומתקדמת המנוהלת באמצעות Node.js ו-Express, שפותחה עבור ניהול מקיף של סטודיו לכושר. המערכת מספקת פתרון כולל לניהול משתמשים והרשאות, מאמנים, תבניות שיעורים, מפגשי אימון ספציפיים, ומערכת רישום חכמה הכוללת מעקב אוטומטי אחר תפוסת המשתתפים.

## 🚀 תכונות מרכזיות

* **אבטחה וניהול הרשאות (Authentication & Authorization):** אימות משתמשים מאובטח מבוסס טוקנים עם בקרת הרשאות לפי תפקידים (`admin` מול משתמש רגיל).
* **ניהול מאמנים (Instructor Management):** פעולות CRUD מלאות עבור מאמנים, כולל תמיכה בחיפוש לפי התמחות וחלוקה לעמודים (Pagination).
* **ניהול מפגשי אימון (Class Sessions):** תזמון וניהול של שיעורים ספציפיים המקושרים לתבניות ולמאמנים, כולל עדכון אוטומטי של מונה הנרשמים (`registeredCount`).
* **ניהול הרשמות (Registrations):** מערכת רישום חכמה המעדכנת בזמן אמת את מכסת המשתתפים בשיעור (הוספה בהרשמה והפחתה בביטול).
* **בדיקות תקינות ונתונים (Validation & Security):** אינטגרציה מול MongoDB Atlas בעזרת סכמות של Mongoose, ולידציות קפדניות וטיפול מרכזי בשגיאות.

## 🛠️ טכנולוגיות

* **סביבת ריצה:** Node.js
* **פריימוורק:** Express.js
* **מסד נתונים:** MongoDB & Mongoose
* **ניהול משתני סביבה:** dotenv

## 📁 מבנה הפרויקט

```text
├── controllers/          # לוגיקת צד-שרת וניהול הבקשות
├── models/               # סכמות ומודלי הנתונים של Mongoose
├── routes/               # ניתוב כתובות ה-API של המערכת
├── middlewares/          # מסנני אימות, הרשאות, ולידציה ובדיקות מותאמות
└── app.js             # נקודת הכניסה וההפעלה של השרת
```
